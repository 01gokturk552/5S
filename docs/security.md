# Güvenlik

- Argon2id password hashing
- Refresh token rotation
- HttpOnly secure session cookies
- CSRF, XSS, SSRF ve upload korumaları
- Backend ve frontend feature authorization
- Organization/server-level RBAC
- Discord OAuth state doğrulaması
- Bot secret ve OAuth token'larının backend'de encrypted saklanması
- Yetki ve kritik işlemlerin audit log'a yazılması

Platform admin ve server admin rol sistemleri ayrıdır. CRM verileri public
endpoint'lerden erişilemez olmalıdır.
