# Abonelik ve Entitlement

Entitlement önceliği:

1. Explicit server override
2. Aktif subscription plan feature
3. Plan-free feature

Explicit DENIED override her zaman kazanır. Explicit GRANTED override plan
ve subscription durumundan bağımsız olarak erişim verebilir.

Abonelik bittiğinde public özellik kilitlenir fakat owner verileri ve geçmiş
veriler silinmez.
