# Discord Entegrasyonu

Discord OAuth2 ve resmi Discord Bot API kullanılacaktır.

Bağlantılar:

- User connection
- Guild connection
- Guild role mappings
- Management team visibility

Minimum OAuth scope ve minimum bot permission kullanılmalıdır.
GUILD_MEMBERS yalnızca gerekli ve onaylı durumlarda, GUILD_PRESENCES ise
varsayılan olarak istenmemelidir.

Username kalıcı kimlik değildir. Discord user ve guild ID'leri external identity
olarak saklanmalıdır.
